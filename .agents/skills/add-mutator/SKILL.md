# 変異演算子の追加

1. [設計の変異演算子の表](../../../docs/design.md#変異演算子)に行を足す。名前は Gremlins と gomutants に同じ演算子があればそれに合わせる。
2. 演算子の字句 1 つの置き換えで表せるかを確かめる。表せない変異（文の削除、戻り値の置き換え）は、構築可能性の判定と個別ビルドの前提を崩すので、先に設計の「変異体の表現」を書き直してから進める。
3. `internal/mutant` の列挙の表のテストに、変異する例と変異しない例（定数、ログ出力の引数、生成ファイル）を足し、失敗を確かめてから列挙を実装する。
4. `internal/schemata` の書き換えのテストに、その演算子を含む式の書き換え後の字句を足す。感染の記録で変異後の演算が `panic` しうるなら、その条件を感染とみなす分岐も足す。
5. `testdata/` の固定モジュールに、`KILLED` と `LIVED` の両方になる例を足し、端から端までのテストで状態を表明する。
6. `mise run verify` を通す。
